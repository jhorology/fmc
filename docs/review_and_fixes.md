# fmc.zsh レビューと修正内容

## 🌟 評価ポイント（素晴らしい点）
1. **オンデバイス特化と堅牢な自己修復（Reflection）ループ**
   `fm` コマンドを使用し、生成 → 静的解析 → エラーがあればLLMにフィードバックして再生成させる仕組みが秀逸。
2. **Pure Zsh で実装された軽量・高機能なトークナイザ**
   あえて「ひらがな」を正規表現に含めないことで助詞を区切り文字として扱い、外部ライブラリなしで高度な日本語TF-IDFベクトル検索を実現。
3. **BSD/GNU 差異の徹底した吸収**
   `sed -i` の空文字拡張子の違いなど、macOS環境特有の挙動をハードコードで自動修正・警告している点。
4. **安全なUX設計 (`print -z`)**
   生成されたコマンドを直接実行せず、zshの入力バッファに置くことでユーザーが確認・編集できる設計。

## 🛠 今回の修正内容
評価に基づいて、以下の5点のバグ修正および機能拡張を行いました。

### 1. フラグ解析の漏れ修正（`_fmc_parse_command`）
- **前**: `-[A-Za-z]*` により `-1` などの数字オプションや `--color=auto` などのロングオプションがフラグとして抽出されなかった。
- **後**: `-[A-Za-z0-9-]*` に対応させ、値付きのオプション（`=`）も分離して正しくパースするように修正。未知のGNU特有のロングオプションに対する防御力が向上。

### 2. `man` ページのフラグ抽出正規表現の改善（`_fmc_man_flags`）
- **前**: `-[A-Za-z]+` のみにマッチ。
- **後**: `(^|[^A-Za-z0-9-])--?[A-Za-z0-9-]+` に修正し、`-1` や `--help` などの数字・ロングオプションもキャッシュに含めるように修正。既存のキャッシュディレクトリもクリア済み。

### 3. 複数行コマンドのサポート（`_fmc_sanitize`）
- **前**: 最初の1行のみを抽出していたため、複数行のコードブロックが生成されると構文エラーになっていた。
- **後**: マークダウンのコードブロック (` ```zsh ` など) を検知した場合、ブロック内の複数行のコードをすべて結合して抽出するように修正。

### 4. 代替コマンドヒントの拡充（`_FMC_CMD_HINTS`）
- macOS標準で入っていない便利なLinuxコマンドに対して、代替コマンドを提示するように追加。
  - `tree` → `find . -print | sed ...` または `find .`
  - `route` → `netstat -nr`
  - `watch` → `while true; do clear; <cmd>; sleep 2; done`
  - `locate` → `mdfind -name`
  - `rename` → `mv` を使った `for` ループ

### 5. コードの可読性向上
- `_fmc_features` の関数コメントに、あえてひらがなを無視して助詞を区切り文字として活用している意図を明記。

### `_FMC_VALUE_OPTS` の案の問題点

`_fmc_validate` に実際にかけて確認しました。

- `tail -n -3 a.txt` (BSD の tail でも正しい) が `"tail" has no option -3` と誤って指摘されていた。`tail -n` の追加で直る。
- `grep -n` は値を取らない (行番号を出すだけ)。表に入れると次の語を読み飛ばし、`grep -n -P` のような存在しないフラグを見逃す。grep で値を取るのは `-e -f -m -A -B -C`。
- `head -n -5` はすでに「BSD head does not accept negative counts」と指摘されており、`head -n` の追加で重複していた `no option -5` の指摘が消えるだけ。
- `sed -e` と `tar -f` は、値が `-` で始まる場面がまれ。`tar -czf` のようにまとめて書くと表と一致せず、`tar -cf -` はすでに誤検知なしで通るため、追加しない。

## 修正内容

### `fmc.zsh`

- `_FMC_CMD_HINTS` に次の代替を追加しました。コマンドが `whence` で見つからないときだけ表示されるため、Homebrew で ImageMagick などを入れている環境には影響しません。
  - `convert` / `magick` → `sips` (`sips -Z 800` でリサイズ、`sips -s format jpeg` で形式変換)
  - `identify` → `sips -g pixelWidth -g pixelHeight` (画像サイズ) または `mdls` (メタデータ)
  - `exiftool` → `mdls` (メタデータ) または `sips -g all` (画像のプロパティ)
- `_FMC_VALUE_OPTS` に次の項目を追加しました。
  - `head` / `tail`: `-n` `-c`
  - `grep`: `-e` `-f` `-m` `-A` `-B` `-C`

### 回帰テスト (`tests/check.zsh`)

個別ケースを 6 件追加しました。

- 指摘なしになること: `tail -n -3`、`tail -n +2`、`grep -e -v`、`grep -m 1 -e -v`
- 指摘が残ること: `head -n -5` (負の数)、`grep -n -P` (`-n` の後ろのフラグを読み飛ばさない)

`tail -n -3` のケースは、修正前のコードでは失敗します。
